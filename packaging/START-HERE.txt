 houseCARL  v{{VERSION}}  --  START HERE
========================================================================

houseCARL gives Codex direct, plain-English access to your Skyrim SE load
order: read records, inspect conflicts, author reviewable patches, work with
assets and scripts, and use the bundled specialist skills.


INSTALL  (recommended for modders)
------------------------------------------------------------------------

  1. Double-click houseCARL-Setup.exe in this folder.

  2. Fully restart Codex. Close every Codex window and terminal session,
     then reopen it so the MCP server and skills reload.

  3. Tell houseCARL which MO2 instance to use, with YOUR path:

         set my houseCARL MO2 instance to D:\Modding\MO2

     Use the folder containing ModOrganizer.ini.

  4. Try it:

         "what does my Skyrim load order look like?"
         "which plugins override IronSword, and who wins?"


CODEX PLUGIN INSTALL  (alternative)
------------------------------------------------------------------------

  From this folder:

      codex plugin marketplace add .
      codex plugin add housecarl@housecarl

  Restart Codex afterward. Use either this method or houseCARL-Setup.exe;
  installing both creates duplicate registrations.


UPDATING
------------------------------------------------------------------------

  Fully quit Codex before re-running setup or updating the plugin. A running
  session holds the server executable open; setup detects that and refuses
  before copying anything.


REQUIREMENTS
------------------------------------------------------------------------

  - Windows x64.
  - .NET Runtime 9.0 AND ASP.NET Core Runtime 9.0:
        https://dotnet.microsoft.com/download/dotnet/9.0
  - OpenAI Codex with plugin support.
  - Mod Organizer 2 with a modlist. MO2 does not need to be running.
